About

A dark room for good apps

NOIR is a small, independent catalogue of Android apps and games. No mirrors, no installers, no clutter — just honest listings that link to the official store.

How NOIR works

  • ✓Every listing points to Google Play or F-Droid — the developer's own page.
  • ✓We never host, re-pack or mirror APKs, so you always install a signed build.
  • ✓No accounts, no telemetry, no advertising network behind the page.
  • ✓Saved apps stay in your browser's local storage.

Technology

The whole site runs on the Python standard library: one threaded HTTP server, server-rendered templates and a single JSON catalogue. There is no build step, no framework and no client-side framework. The only JavaScript shipped handles search, the mobile menu and bookmarks.

Every app page is rendered from one shared template, so a new entry in the catalogue is automatically a complete, fully working detail page with ratings, screenshots, metadata and official links.
